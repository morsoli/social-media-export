## Fonctionnalités

- Exportez en CSV les publications, commentaires, informations sur les auteurs et statistiques disponibles.
- Enregistrez les pages publiques et les publications en Markdown modifiable, avec les images disponibles dans un ZIP.
- Enregistrez les fichiers localement ou envoyez le contenu vers Feishu/Lark ou Notion après configuration.

L’export local s’exécute dans le navigateur et ne nécessite pas de compte SocialExport.
