Une extension de navigateur gratuite qui privilégie le traitement local pour la recherche sur les réseaux sociaux et la collecte de pages web.

[![SocialExport English homepage](assets/website-overview-en.png)](https://socialexport.app/)

## Contenus exportables

### Données des réseaux sociaux

Exportez en CSV les publications, commentaires, informations sur les auteurs et statistiques disponibles. Ouvrez le CSV dans un tableur pour vos analyses et rapports. Les champs disponibles varient selon la plateforme et la page.

#### Cinq axes de collecte

1. **Médias** — Enregistrez les vidéos, sons, images originales et couvertures disponibles.
2. **Publications** — Exportez les identifiants, URL, titres, textes, auteurs, dates et indicateurs d’engagement disponibles.
3. **Commentaires** — Exportez le texte, l’auteur, la date et les réponses accessibles.
4. **Profils de créateurs** — Collectez l’URL, le nom de compte, la biographie, la vérification et le nombre d’abonnés disponible.
5. **Publications d’un créateur** — Dressez une liste des URL, titres, dates et indicateurs accessibles depuis un profil ou une collection compatible.

Les champs disponibles varient selon le site et le type de page. Les données structurées peuvent être exportées en CSV.

### Contenus web publics

Enregistrez les pages publiques et les publications en Markdown modifiable, avec les images disponibles dans un ZIP. Conservez titres, liens et texte dans un Markdown modifiable, avec les images accessibles réunies dans un ZIP.

La capture préserve les titres, liens, tableaux, blocs de code et formules lisibles sur les pages et publications accessibles.

### Export des conversations IA

Copiez le Markdown ou téléchargez un fichier Markdown ou ZIP depuis une conversation ou un lien de partage lisible. Connectez-vous au service d’origine si nécessaire.

ChatGPT, Claude, Gemini, Google AI Studio, DeepSeek, Kimi, Doubao, Tencent Yuanbao, Qwen, Zhipu (ChatGLM), Grok, Perplexity.

## Destinations

Téléchargez les données sociales en CSV et les pages ou conversations en Markdown ou ZIP. Configurez Feishu/Lark (Base ou Docs) ou Notion (base de données ou page) pour les y enregistrer.

Le mode URI ouvre une note Markdown dans Obsidian. Pour joindre les images accessibles au coffre, configurez Obsidian Local REST API et activez la synchronisation des images.

## Confidentialité et accès

L’extraction et l’export local se font dans le navigateur, sans compte SocialExport. Respectez les droits d’accès, les règles des plateformes, le droit d’auteur et la vie privée.
