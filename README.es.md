Una extensión de navegador gratuita centrada en el procesamiento local para investigar redes sociales y archivar páginas web.

[![SocialExport English homepage](assets/website-overview-en.png)](https://socialexport.app/)

## Qué puedes exportar

### Datos de redes sociales

Exporta a CSV las publicaciones, los comentarios, los datos de autores y las métricas disponibles. Abre el CSV en una hoja de cálculo para investigar y preparar informes. Los campos dependen de la plataforma y el tipo de página.

#### Cinco dimensiones de recopilación

1. **Contenido multimedia** — Guarda vídeos, audio, imágenes originales y portadas disponibles.
2. **Datos de publicaciones** — Exporta ID, URL, título, texto, autor, fecha y métricas disponibles.
3. **Comentarios** — Exporta el texto, autor, fecha y respuestas accesibles.
4. **Perfil del creador** — Recopila URL, usuario, biografía, verificación y cifras de seguidores disponibles.
5. **Publicaciones del creador** — Crea un listado de URL, títulos, fechas y métricas disponibles desde un perfil o una colección compatible.

Los campos dependen de la plataforma y del tipo de página. Los datos estructurados se pueden exportar a CSV.

### Contenido web público

Guarda páginas y publicaciones públicas como Markdown editable y empaqueta las imágenes disponibles en un ZIP. Conserva encabezados, enlaces y texto en Markdown editable, con las imágenes accesibles en un archivo ZIP.

El recorte conserva los encabezados, enlaces, tablas, bloques de código y fórmulas legibles de páginas y publicaciones.

### Exportar conversaciones con IA

Copia Markdown o descarga un archivo Markdown o ZIP desde una conversación o un enlace compartido legible. Inicia sesión en el servicio original cuando sea necesario.

ChatGPT, Claude, Gemini, Google AI Studio, DeepSeek, Kimi, Doubao, Tencent Yuanbao, Qwen, Zhipu (ChatGLM), Grok, Perplexity.

## Destinos de exportación

Descarga los datos de redes sociales en CSV y los recortes o conversaciones en Markdown o ZIP. Configura Feishu/Lark (Base o Docs) o Notion (bases de datos o páginas) para guardarlos allí.

El modo URI abre una nota Markdown en Obsidian. Para guardar imágenes en la bóveda, configura Obsidian Local REST API y activa la sincronización de imágenes.

## Privacidad y acceso

La extracción y la exportación local se realizan en el navegador y no requieren una cuenta de SocialExport. Respeta los permisos, las normas de cada plataforma, los derechos de autor y la privacidad.
